# Simulasi dan Permodelan
Simulasi Monte Carlo (Peminjaman Buku Perpustakaan)

🔎 Deskripsi

Ini adalah proyek yang dibangun dengan metode Monte Carlo dengan tujuan memprediksi jumlah peminjam buku di sebuah perpusatakaan dalam hitungan harian berdasarkan histori yang ada.

📑 Sumber Data

Jenis Data: Data historis jumlah peminjam buku perpustakaan dalam 100 hari pengamatan.

Variabel Data: 

🔹 Jumlah Peminjam (0, 1, 2, 3, dan 4+ buku)

🔹 Frekuensi kemunculan harian (5, 10, 40, 30, dan 15 hari)

🔹 Distribusi probabilitas (0.05, 0.10, 0.40, 0.30, dan 0.15)

🔹 Probabilitas kumulatif (0.05, 0.15, 0.55, 0.85, dan 1.00)

🔹 Interval bilangan acak (1 - 100)


💻 Bahasa Pemrograman & Tools

🔹 Bahasa Pemrograman: Python 3

🔹 Environment: Google Colab

🔹 Library yang Digunakan: 'random' (Standard Python Library untuk membangkitkan bilangan acak numerik)
